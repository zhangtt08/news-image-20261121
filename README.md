A newspaper front page summing up Saturday 21 November 2026: Poland seeks
more NATO air defences after Russian missiles land on its soil; Asian markets
plunge as the Wall Street AI rout spreads; COP31 runs into overtime over
fossil fuels; BepiColombo enters orbit around Mercury after eight years; a
magnitude 6.7 earthquake shakes Peru; and Jair Bolsonaro is taken to hospital
in Brasilia. The image is drawn by `build_image.py` (PIL) and `main.py`
copies it to the output directory.

## Run it

```sh
python3 build_image.py        # draws news.png (1024x1024, under 1 MiB)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```
